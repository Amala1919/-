# クロノアトラス（Chrono Atlas）

**国と時代、ふたつの軸で世界の歴史を旅する Android アプリ**

年代順に世界を見渡すだけでなく、「日本」「中国」「ローマ」など国・地域ごとに、はじまりから現代までの歴史をたどれます。
3D の地球儀や建造物モデル、**本物の写真や名画**（約870枚）、イラスト、似顔絵などグラフィカルな表現をたくさん使い、確認クイズで楽しく復習できます。

## インストール（Android）

1. このリポジトリの [`dist/ChronoAtlas.apk`](dist/ChronoAtlas.apk) をスマホでダウンロード
2. 開いてインストール（初回は「提供元不明のアプリ」のインストール許可を求められます）
3. ホーム画面の「クロノアトラス」をタップ

- 対応: Android 7.0 以上（3D 表示には WebGL 対応端末が必要。ほぼすべての端末が対応）
- インターネット接続は不要です（写真を含むすべてのデータをアプリ内に収録。APK は約 53MB）

## プロジェクト構成

```
web/                    アプリ本体（HTML/CSS/JavaScript, Three.js, d3-geo）
  src/data/             歴史データ（時代・国ごとの出来事・人物・クイズ・画像の対応表）
  public/img/           写真（Wikimedia Commons から取得）
  src/three/            3D（地球儀・モデルビューア・28 の手続き的 3D モデル）
  src/views/            各画面
  src/components/       地図・似顔絵・時代イラスト・シートなどの部品
android/                Android アプリ（WebView でアプリ本体を表示）
  app/src/main/assets/www/   ビルド済みのアプリ本体（web から生成）
scripts/build-apk.sh    Gradle を使わずに APK を作るスクリプト
dist/ChronoAtlas.apk    ビルド済み APK
```

Android 側は WebView にアプリ本体を読み込む薄いシェルで、読み上げ（Android の TextToSpeech）、
バイブレーション、共有、戻るボタンをネイティブ機能として JavaScript に提供しています。

## 開発

```bash
cd web
npm install
npm run dev      # http://localhost:8123/index.html でブラウザ確認（スマホ幅で表示推奨）
npm run build    # android/app/src/main/assets/www に出力
```

### APK のビルド

**方法 1: コマンドライン（Ubuntu/Debian）** — `dist/ChronoAtlas.apk` はこの方法で作っています。

```bash
sudo apt-get install aapt apksigner dalvik-exchange zipalign android-sdk-platform-23
./scripts/build-apk.sh
```

**方法 2: Android Studio / Gradle** — `android/` フォルダを Android Studio で開いてビルド、または

```bash
cd web && npm install && npm run build && cd ../android && ./gradlew assembleDebug
```

どちらも同じ署名鍵（`android/debug.keystore`、個人利用向けの鍵）で署名されるため、上書きアップデートできます。
Google Play などで公開する場合は、自分専用の鍵に差し替えてください。

GitHub Actions（`.github/workflows/android.yml`）でも両方の方法で APK をビルドし、成果物としてダウンロードできます。

## データについて

- 歴史の解説・クイズは一般的な教科書レベルの内容をもとに作成しています。年代には諸説あるものがあり、その場合は本文中に記しています。
- 地図データ: [Natural Earth](https://www.naturalearthdata.com/)（パブリックドメイン）via world-atlas
- 3D モデル・イラスト・似顔絵はプログラムで生成しています。
- 写真・絵画は [Wikimedia Commons](https://commons.wikimedia.org/) のパブリックドメインまたはクリエイティブ・コモンズ等の自由なライセンスの画像です。作者とライセンスはアプリ内（各画像の下、および「マイページ → 画像クレジット」）と `web/src/data/image-credits.json` に記載しています。

### 画像の追加・更新

出来事・人物・国・3D モデルに英語版 Wikipedia の記事名（`img`、または `web/src/data/wiki.js`）を指定し、
`node scripts/gen-image-manifest.mjs` で `scripts/images.json` を更新して push すると、
GitHub Actions（`.github/workflows/images.yml`）がその記事の代表画像を Wikimedia Commons から取得し、
自由なライセンスのものだけを縮小して `web/public/img` にコミットします（結果は `scripts/images-report.txt`）。
